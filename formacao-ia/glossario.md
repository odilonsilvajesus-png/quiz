# Glossário da formação

**Os termos técnicos da formação, em ordem alfabética, com o módulo onde cada um é explicado**

Use este glossário sempre que encontrar um termo que não lembra. A coluna "Onde estudar" indica o módulo e a aula em que o conceito é explicado em detalhe.

## A a D

| Termo | O que significa | Onde estudar |
|---|---|---|
| **ADKAR** | Modelo de gestão da mudança com 5 etapas: consciência, desejo, conhecimento, habilidade e reforço | M10, Aula B.5 |
| **Agente de IA** | Modelo de IA em um laço: recebe um objetivo, escolhe ferramentas, observa os resultados e decide o próximo passo até concluir | M9, Aula 9.1 |
| **AIDA** | Estrutura de texto persuasivo: Atenção, Interesse, Desejo, Ação | M7, Aula 7.2 |
| **Alucinação** | Informação falsa gerada pela IA com aparência de verdadeira | M1, Aula 1.4 |
| **ANPD** | Autoridade Nacional de Proteção de Dados: fiscaliza e orienta sobre a LGPD | M10, Aula B.1 |
| **API** | "Porta" que um sistema abre para outros sistemas conversarem com ele de forma automática | M5, Aula 5.2 |
| **Automação (workflow)** | Sequência de passos que roda sozinha quando um gatilho acontece; os passos são definidos antecipadamente | M5, Aula 5.1 |
| **Banco vetorial** | Banco de dados especializado em encontrar textos parecidos em significado, usando embeddings | M8, Aula 8.2 |
| **BANT** | Método de qualificação de vendas: orçamento, autoridade (decisor), necessidade e prazo | M6, Aula 6.2 |
| **Base legal** | Justificativa prevista na LGPD para tratar dados pessoais (consentimento, contrato, legítimo interesse etc.) | M10, Aula B.1 |
| **Caso de negócio** | Documento de 1 página que justifica um projeto: problema, solução, benefícios, investimento, payback e riscos | M10, Aula A.3 |
| **Chunking (divisão em trechos)** | Divisão de documentos em pedaços menores para a busca do RAG | M8, Aula 8.2 |
| **Controlador** | Na LGPD, quem decide por que e como os dados pessoais são tratados (normalmente, a empresa cliente) | M10, Aula B.1 |
| **Credencial** | Acesso guardado a um sistema (login, chave de API) dentro de uma ferramenta de automação | M5, Aula 5.1 |
| **Curva ABC** | Classificação dos produtos pela participação no faturamento (A: poucos itens, maior parte do faturamento) | M8, Aula 8.1 |
| **Dados sensíveis** | Categoria especial da LGPD: saúde, origem racial ou étnica, religião, opinião política, filiação sindical, vida sexual, dados genéticos e biométricos | M10, Aula B.1 |
| **Data de corte** | Momento até o qual o modelo foi treinado; ele não conhece fatos posteriores sem receber essas informações | M1, Aula 1.2 |
| **Diagnóstico em 5 camadas** | Avaliação da prontidão da empresa para IA em Estratégia, Processos, Dados, Pessoas e Tecnologia | M3, Aula 3.2 |

## E a L

| Termo | O que significa | Onde estudar |
|---|---|---|
| **Embedding** | Representação numérica do significado de um texto; textos parecidos em sentido ficam "próximos" | M8, Aula 8.2 |
| **Encadeamento de prompts** | Divisão de uma tarefa em etapas, em que a saída de uma é a entrada da próxima | M2, Aula 2.3 |
| **Ferramenta (tool)** | Função que um agente pode chamar, com nome, descrição e parâmetros | M9, Aula 9.2 |
| **Few-shot** | Técnica de mostrar ao modelo alguns exemplos de entrada e saída antes do pedido | M2, Aula 2.3 |
| **Fluxograma** | Desenho de um processo com atividades, decisões, início e fim | M3, Aula 3.4 |
| **Gatilho (trigger)** | Evento que inicia uma automação (e-mail recebido, formulário enviado, horário agendado) | M5, Aula 5.1 |
| **Guia de marca para IA** | Documento com público, tom de voz, palavras e regras da marca, usado como contexto em todo pedido de conteúdo | M7, Aula 7.1 |
| **Humano no circuito** | Etapa de aprovação humana antes que a saída da IA seja enviada ou executada | M5, Aula 5.3 |
| **IA generativa** | Tipo de Machine Learning que gera conteúdo novo (texto, imagem, áudio, código) | M1, Aula 1.1 |
| **Janela de contexto** | Quantidade máxima de tokens que o modelo considera de uma vez (instruções, documentos, histórico e resposta) | M1, Aula 1.3 |
| **Janela de 24 horas (WhatsApp)** | Período após a última mensagem do cliente em que a empresa pode responder livremente; fora dele, só com modelos aprovados | M6, Aula 6.3 |
| **JSON** | Formato de texto estruturado usado para troca de dados entre sistemas | M5, Aula 5.2 |
| **Latência** | Tempo que o sistema leva para responder | M9, Aula 9.5 |
| **Lean** | Metodologia de gestão focada em eliminar desperdícios | M3, Aula 3.4 |
| **LGPD** | Lei Geral de Proteção de Dados (Lei nº 13.709/2018) | M10, Aula B.1 |
| **LLM** | Modelo de linguagem de grande escala (Large Language Model): o motor de Claude, ChatGPT e Gemini | M1, Aula 1.2 |
| **LLM como juiz** | Uso de uma IA para avaliar as respostas de outra com base em critérios | M2, Aula 2.5 |

## M a P

| Termo | O que significa | Onde estudar |
|---|---|---|
| **Machine Learning** | Sistemas que aprendem padrões a partir de dados, em vez de seguir regras escritas | M1, Aula 1.1 |
| **Matriz Impacto × Esforço** | Gráfico de 4 quadrantes para priorizar oportunidades (quick wins, projetos estratégicos, complementares, evitar) | M3, Aula 3.5 |
| **MCP (Model Context Protocol)** | Padrão aberto para conectar modelos de IA a ferramentas e sistemas, como uma "tomada universal" | M9, Aula 9.4 |
| **Menor privilégio** | Princípio de segurança: dar a um sistema só as permissões estritamente necessárias | M9, Aula 9.2 |
| **Minimização** | Princípio da LGPD: tratar só os dados necessários para a finalidade | M10, Aula B.1 |
| **Modelo multimodal** | Modelo que entende mais de um tipo de entrada, como texto e imagem | M1, Aula 1.5 |
| **Modo sombra** | Etapa do piloto em que a IA sugere respostas e um humano revisa e envia | M6, Aula 6.5 |
| **n8n / Make / Zapier** | Ferramentas de automação que conectam sistemas sem (ou com pouca) programação | M5, Aula 5.1 |
| **OCR** | Reconhecimento de texto em imagens e documentos escaneados | M8, Aula 8.3 |
| **Operador** | Na LGPD, quem trata dados pessoais em nome do controlador (você, fornecedores de IA) | M10, Aula B.1 |
| **PAS** | Estrutura de texto persuasivo: Problema, Agitação, Solução | M7, Aula 7.2 |
| **Payback** | Tempo para recuperar o investimento: investimento inicial ÷ benefício líquido mensal | M10, Aula A.2 |
| **PCTRFE** | Método de prompt: Papel, Contexto, Tarefa, Restrições, Formato, Exemplos | M2, Aula 2.2 |
| **Pilares de conteúdo** | Temas fixos de uma marca com proporção definida (educação, prova, bastidores, oferta) | M7, Aula 7.3 |
| **Pontuação de Oportunidade** | F × T × P × (6 − R): frequência, tempo, padronização e risco, cada um de 1 a 5 | M3, Aula 3.5 |
| **Prompt** | Tudo o que é enviado ao modelo: instrução, contexto, dados e exemplos | M2, Aula 2.1 |
| **Prompt de sistema** | Instrução permanente que define o comportamento de um assistente em todas as conversas | M2, Aula 2.4 |
| **Prompt injection (manipulação por instruções)** | Tentativa de manipular a IA com instruções escondidas em mensagens ou documentos | M9, Aula 9.5 |

## Q a Z

| Termo | O que significa | Onde estudar |
|---|---|---|
| **Quick win** | Oportunidade de alto impacto e baixo esforço, ideal para começar | M3, Aula 3.5 |
| **RAG** | Geração aumentada por recuperação: a IA busca trechos dos documentos da empresa e responde com base neles | M8, Aula 8.2 |
| **Regressão** | Quando o ajuste de um prompt corrige um caso e piora outro | M2, Aula 2.5 |
| **Roadmap de 90 dias** | Plano em 3 blocos de 30 dias com responsáveis, indicadores, metas e prazos | M3, Aula 3.6 |
| **ROI** | Retorno sobre o investimento: (benefício líquido − investimento) ÷ investimento | M10, Aula A.2 |
| **Roteador (router / switch)** | Etapa de uma automação que divide o fluxo em caminhos diferentes | M5, Aula 5.1 |
| **Semáforo de dados** | Classificação dos dados em público, interno, confidencial e restrito, para decidir o que vai para cada ferramenta | M10, Aula B.2 |
| **SIPOC** | Mapa macro de um processo: Fornecedor, Entrada, Processo, Saída, Cliente | M3, Aula 3.4 |
| **Stack** | Conjunto de ferramentas usado por uma empresa | M4, Aula 4.4 |
| **Temperatura** | Parâmetro que controla o quanto a resposta varia (baixa: previsível; alta: criativa) | M1, Aula 1.3 |
| **Token** | Unidade de texto que o modelo lê e pela qual as APIs cobram (cerca de 3 a 4 caracteres em português) | M1, Aula 1.3 |
| **Top-k** | Quantos trechos o RAG recupera para cada pergunta | M8, Aula 8.2 |
| **Webhook** | URL que recebe dados de outro sistema em tempo real, quando um evento acontece | M5, Aula 5.1 |
