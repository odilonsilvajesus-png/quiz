# Trilha B: Casos de uso por área

**Quando estudar:** ao longo dos Níveis 3 e 4, conforme as necessidades das suas empresas-laboratório.
**Meta:** dominar **pelo menos 4 casos a fundo** (construir e implantar) e conhecer todos o suficiente para identificá-los num diagnóstico.

Cada caso traz:
- o problema típico e os sinais no diagnóstico;
- a arquitetura de referência;
- o passo a passo de implementação;
- cuidados (técnicos, LGPD, pessoas);
- métricas;
- um laboratório.
